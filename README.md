# Чистка заявок

Скрипт приводит файл заявок к единому виду: нормализует телефон, дату, имя,
убирает дубли по телефону, проблемные строки выносит отдельно.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install pandas openpyxl
.venv/bin/python clean_requests.py <входной_файл.xlsx>
```

На Windows пути к venv другие:
```bat
python -m venv .venv
.venv\Scripts\pip install pandas openpyxl
.venv\Scripts\python clean_requests.py <входной_файл.xlsx>
```

На выходе — один файл `заявки_результат.xlsx` с двумя листами:
- «Чистые» — чистые уникальные записи
- «Проблемные» — строки с проблемами + причина

Опции (необязательно, по умолчанию результат кладётся рядом со скриптом
в файл `заявки_результат.xlsx`):
```bash
python3 clean_requests.py <входной_файл.xlsx|.csv|.txt> \
  --out-dir result \
  --out-name результат.xlsx
```

Работает с любым файлом такой же структуры (колонки: Имя, Телефон, Дата заявки, Источник),
поддерживает .xlsx и .csv/.txt на входе.

## Правила нормализации

- **Телефон** → `+7XXXXXXXXXX`. Извлекаются только цифры; 11 цифр с 7/8 в начале
  или 10 цифр — принимаются. Иначе — «нет телефона».
- **Дата** → `ГГГГ-ММ-ДД`. Понимает `12.03.2026`, `2026/03/13`, `13 марта 2026`,
  `22.03.26` (2-значный год), `03/15/2026` (день>12 → трактуется как mm/dd).
  Без года или нечисловой мусор — «битая дата».
- **Имя** → каждое слово с заглавной буквы, лишние пробелы убраны.
- **Дубли** — по нормализованному телефону, оставляется первая встреченная запись.
- **Проблемные строки** (нет телефона / битая дата / нет имени) — в отдельный
  файл с исходными значениями и причиной, из чистого файла исключены.
